# Visual Principles

Non-technical north stars. Tools and code change; these don't. When a new idea appears, check it
against these before building anything.

1. **Every card should feel premium.**
2. **Every card should be readable in under 2 seconds.**
3. **The background must never compete with the text.**
4. **The accent color guides attention** — one accent, used intentionally.
5. **Empty space is intentional**, not leftover.
6. **Consistency over novelty** — a recognizable system beats a clever one-off.
7. **Information first, decoration second.**
8. **Simplicity over cleverness** — every addition must remove complexity somewhere else.

### How to use these
- When unsure whether to add an element, ask: *does it serve readability or brand recognition?* If
  not, cut it (see "every visual element must justify its existence" in
  [ARCHITECTURE.md](ARCHITECTURE.md) → Design Constraints).
- When two options look equally good, pick the **simpler and more consistent** one.
